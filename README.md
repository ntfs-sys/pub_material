# Конспекты и учебные материалы 📚

Сборник лекций, разборов практик, формул и шпаргалок, оформленный как **Obsidian-сейф**. Репозиторий пополняется постепенно — сейчас основная движуха в разделе с физикой, но архитектура уже заложена на вырост.

## 🧭 Как тут всё устроено

Материалы разложены по семестрам (`S1` — `S4`), а внутри — по предметам. 

```text
.
├── S1/                # Семестры
│   └── <Предмет>/     # Конкретная дисциплина
│       ├── lecture/   # Лекции и теория
│       ├── practice/  # Разборы задач и семинаров
│       ├── exam/      # Билеты и ответы к сессии
│       ├── attachments/ # Картинки, графики и схемы
│       ├── formulas.md  # Выжимка формул
│       └── index.md     # Оглавление по предмету
├── CTF/               # Заметки и таски по информационной безопасности
└── LaTeX. *.md        # Шпаргалки по верстке формул
```
коч 67 голда не на балике, чувак это репчик, свага, ридми, мистер робот, роботсточка тхт, секретный дипсик апи, айлюлю, кебаб
