# Программный продукт Unigraphics NX

**Unigraphics NX** — это мощная система автоматизированного проектирования (САП), объединяющая инструменты для трёх ключевых этапов работы с изделием: **CAD**, **CAM** и **CAE**.

---

## Ключевые направления

### CAD — проектирование
Отвечает за проектирование трёхмерной геометрии и создание полного комплекта чертёжно-графической документации.

Включает инструменты для:
- твердотельного и поверхностного моделирования;
- создания сложных сборок;
- формирования чертежей с учётом размеров и допусков;
- параметризации модели.

### CAE — инженерный анализ
- Решатели для конечно-элементного анализа;
- инструменты для мультифизического моделирования;
- оптимизация технологий.

### CAM — подготовка к производству
- Модули для подготовки управляющих программ для станков с числовым программным управлением (ЧПУ);
- поддержка постпроцессоров для конкретных моделей оборудования.

---

## Особенности

| Особенность | Описание |
|---|---|
| **Синхронная технология моделирования** | Позволяет работать с геометрией напрямую, не углубляясь в параметрические зависимости, что ускоряет процесс проектирования |
| **Модульность** | Возможность выбирать и комбинировать только те модули, которые необходимы для решения конкретных задач |
| **Расширяемость** | Можно создавать пользовательские приложения с использованием языков программирования |
| **Ассоциативные связи** | При изменении моделей автоматически обновляются связанные с этой моделью данные (например, траектория инструмента в CAM-модуле) |
