# Vuforia

**Vuforia** — программная платформа (и набор сопутствующих инструментов) для создания приложений дополненной реальности.

Позволяет накладывать цифровой контент, включающий трёхмерные модели, видео и текст, на реальный мир. При этом могут использоваться камеры смартфонов, планшетов или специальные AR-очки.

## Основные модули Vuforia

- **Vuforia Engine** — основа, набор средств разработки. Туда входят библиотеки и инструменты, позволяющие добавлять в приложение функции дополненной реальности.
- **Vuforia Studio** — компонент, работающий с трёхмерными моделями; позволяет помещать цифровые объекты в реальную физическую обстановку.
- **Vuforia Expert Capture** — инструмент, предназначенный для фиксации экспертного опыта; с его помощью создают интерактивные технические руководства, которые можно просматривать на мобильных устройствах или с помощью AR-очков.
- **Vuforia Chalk** — компонент, необходимый для совместной работы в реальном времени; например, позволяет эксперту и пользователю видеть одну и ту же сцену и привязывать виртуальный контент к реальным объектам.

## Возможности

- **Image Targets** — данный инструмент позволяет работать с плоскими изображениями-маркерами.
- **Model Targets** — инструмент для распознавания реальных трёхмерных объектов по их цифровой модели.
- **Ground Plane** — предназначен для безмаркерного размещения виртуальных объектов.
- **Multi Targets** — инструмент для одновременного отслеживания нескольких связанных маркеров.
- **VuMarks** — инструмент настройки маркеров.
- Работа с AR-очками.
- Обработка текста в реальном времени.
- Облачное хранение маркеров.

# LayAR

**LayAR** — продукт для работы с дополненной реальностью; используются смартфоны.

## Идея продукта

Наложение цифрового контента на реальную картину с камеры устройства в реальном времени.

## Принцип работы

Приложение использует данные с камеры и определяет местоположение пользователя. Необходимая информация организована в виде слоёв. Пользователь выбирает нужный слой, и на экране появляются виртуальные объекты или данные, привязанные к реальным окружающим объектам.

## Применение

Наибольшее применение продукт нашёл в **образовании**. То есть, наведя камеру устройства на объект (например, здание), можно увидеть его характеристики или историю.
# Unity

**Unity** — кроссплатформенная среда разработки виртуальной реальности, игровой движок, позволяющий создавать игры, интерактивные приложения, симуляторы, а также различные проекты в сфере виртуальной и дополненной реальности. Разработка принадлежит американской компании **Unity Technologies**, первая версия вышла в **2005 году**.

## Использование

- Разработка игровых проектов — от 2D до 3D масштабных проектов с современной графикой и физикой.
- Создание интерактивного контента: виртуальные тренажёры, презентации, симуляторы.
- Архитектурная визуализация и промышленный дизайн: применяется для создания реалистичных трёхмерных моделей зданий, интерьеров, оборудования.
- Разработка медицинских тренажёров и т. п.

## Ключевые особенности

- **Кроссплатформенность** — один и тот же код может быть скомпилирован под разные платформы: например, ПК, консоли, Android/iOS, VR/AR.
- **Визуальный редактор** — в Unity позволяет собирать игровые сцены, настраивать свет, видеть результат в единой системе, то есть не переключаясь между разными программами.
- **Компонентная модель** — поведение объекта задаётся путём сборки из отдельных компонентов; например, для персонажа можно подобрать набор, включающий компоненты физики, анимации, логики и ряд других.
- **Поддержка различных направлений** — движок одинаково хорошо работает в двух- и трёхмерной постановке, а также с технологиями виртуальной и дополненной реальности.
- **Обширная экосистема** — Unity имеет собственный магазин ассетов (готовый цифровой объект); здесь можно найти готовые модели, скрипты, эффекты, шаблоны проектов.

## Основные определения

- **Сцена** — отдельное пространство, где размещаются все игровые объекты.
- **Игровой объект** — базовый объект в сцене, например персонаж, камера, источник света и т. п.
- **Компонент** — модуль, который добавляет объекту определённое поведение, например: физика, анимация, звук, логика.
- **Скрипт** — программный код, как правило на языке C#, необходим для управления, например логикой игры.
# Blender

**Blender** — профессиональное открытое программное обеспечение для создания трёхмерной компьютерной графики. В данном программном продукте объединяются инструменты для моделирования, анимации, рендеринга, симуляции, базового видеомонтажа.

## Основные возможности

- **Трёхмерное моделирование** — создание объектов, персонажей, окружения любой сложности с использованием полигонов, поверхностей, трёхмерных примитивов, других методов.
- **Скульптинг** — цифровая лепка форм, аналогично работе с глиной, но с использованием инструментов трёхмерного моделирования.
- **Анимация** — в программе реализована возможность анимации от простой покадровой до сложной скелетной анимации. Доступны инструменты прямой и обратной кинематики, нелинейной анимации, а также элементы с различными ограничениями.
- **Рендеринг** — создание финальных изображений или видео с помощью встроенных движков.
- **Симуляция физики** — в программе реализована возможность моделирования динамики твёрдых и мягких тел, жидкостей, дыма, огня и различного рода разрушений.
- **Работа с материалами и текстурами** — в программе реализована возможность настройки внешнего вида поверхностей с помощью системы нодов.
- **Двухмерная графика** — данный элемент позволяет рисовать и анимировать прямо в трёхмерном пространстве, а также работать с векторной графикой.
- **Композиторинг и видеомонтаж** — встроенный видеоредактор для базовой сборки анимации.
- **Генеративный дизайн** — создание множества вариантов решений на основе заданных параметров.

## Области применения

- Кино и анимация
- Игровая индустрия
- Архитектура и дизайн
- Реклама и спецэффекты
- 3D-печать
