# Множества на комплексной плоскости. Функции комплексного переменного

## Множества на комплексной плоскости

Пусть $z = x + iy$ — комплексная переменная, где $i = \sqrt{-1}$, $x, y \in \mathbb{R}$. При изменении $x$ и $y$ переменная $z$ «пробегает» некоторое множество точек комплексной плоскости $\mathbb{C}$.

>**Расстояние между точками** $\rho(z_1, z_2)$ — величина

$$\rho(z_1, z_2) = \sqrt{(x_1 - x_2)^2 + (y_1 - y_2)^2} = |z_1 - z_2| \tag{1}$$

где $z_1 = x_1 + iy_1$, $z_2 = x_2 + iy_2$.

Уравнение окружности радиуса $R$ с центром в точке $z_0$:

$$|z - z_0| = R \tag{2}$$

Множество точек, лежащих внутри круга радиуса $R$ с центром в $z_0$:

$$|z - z_0| < R \tag{3}$$

Параметрическое уравнение окружности:

$$z = z_0 + Re^{i\varphi}, \quad 0 \le \varphi < 2\pi \tag{4}$$

>**$\delta$-окрестность точки $z_0$** — множество всех точек $z$, удовлетворяющих неравенству $|z - z_0| < \delta$, $\delta > 0$, где $z_0$ — фиксированная точка.

>**Открытое множество** $D$ — множество, всякая точка которого имеет окрестность, целиком принадлежащую $D$ (то есть состоящую только из точек данного множества).

*Пример 1: Открытый круг*  
Множество $D = \{z : |z - z_0| < R\}$ является открытым.

>**Связное множество** $D$ — множество, любые две точки которого можно соединить непрерывной кривой, целиком лежащей в $D$.

>**Область** — открытое связное множество.

**Примеры областей:**

1. круг $|z - z_0| < R$;
2. кольцо $r < |z - z_0| < R$;
3. вся плоскость $\mathbb{C}$;
4. полуплоскость $\operatorname{Re} z > a$, $a \in \mathbb{R}$.

Множество $|z - z_0| \le R$ не является областью, так как не является открытым: для точек $z$, для которых $|z - z_0| = R$, не существует окрестности, целиком лежащей в этом круге.

>**Граничная точка множества $D$** — точка $z_1$, в любой окрестности которой найдутся как точки, принадлежащие $D$, так и точки, ему не принадлежащие.

>**Граница множества $D$** — множество всех граничных точек $D$.

>**Замкнутая область** $\overline{D}$ — множество, состоящее из области $D$ и всех граничных точек области $D$.

Области на плоскости подразделяются на односвязные и многосвязные.

>**Односвязная область** — область, граница которой состоит из одной непрерывной кривой без самопересечений (возможно, замкнутой).

>**Многосвязная область** — область, которая не является односвязной. В частности, **$n$-связная область** — многосвязная область, граница которой состоит из $n$ ($n > 1$) непересекающихся непрерывных кривых (некоторые из кривых могут вырождаться в точку).

## Понятие функции комплексной переменной

Пусть $D$ — некоторое множество комплексных чисел $z$.

>**Комплексная функция комплексной переменной** $w = f(z)$ — правило $f$, по которому каждой точке $z = x + iy$, $x, y \in \mathbb{R}$ из множества $D$ расширенной комплексной $z$-плоскости ставится в соответствие комплексное число $w = u + iv$, $u, v \in \mathbb{R}$ из множества $E$ расширенной комплексной $w$-плоскости.

- $D$ — **область определения** функции комплексного переменного;
- $E$ — **область значений** функции комплексного переменного.

$$w = f(z) = u + iv = f(x + iy) \tag{5}$$

$$f(x + iy) = u(x, y) + iv(x, y) \tag{6}$$

где $u = u(x, y) = \operatorname{Re} f(z)$;  
$v = v(x, y) = \operatorname{Im} f(z)$.

>**Однозначная функция** — функция $w = f(z)$, если каждому значению $z \in D$ соответствует единственное значение $w = f(z)$.

>**Многозначная функция** — функция, для которой это условие не выполняется.

## Предел последовательности комплексных чисел

Пусть задана последовательность $\{z_n\}$ комплексных чисел: $z_1, z_2, \ldots, z_n, \ldots$

>**Предел последовательности** $\{z_n\}$ — комплексное число $a$, если для любого $\varepsilon > 0$ можно указать такой номер $N = N_0$, начиная с которого все элементы $z_n$ этой последовательности удовлетворяют неравенству

$$|z_n - a| < \varepsilon \quad \text{при } n \ge N_0 \tag{7}$$

>**Сходящаяся последовательность** — последовательность, имеющая предел.

Обозначение:

$$\lim_{n \to \infty} z_n = a \tag{8}$$

==**Теорема о покомпонентной сходимости**==

Последовательность $\{z_n = x_n + iy_n\}$ сходится к числу $a = \alpha + i\beta$ тогда и только тогда, когда

$$\lim_{n \to \infty} x_n = \alpha, \quad \lim_{n \to \infty} y_n = \beta \tag{9}$$

>**Ограниченная последовательность** $\{z_n\}$ — последовательность, для которой существует такое число $M > 0$, что для всех $z_n$ выполняется неравенство

$$|z_n| \le M \tag{10}$$

==**Теорема об ограниченности сходящейся последовательности**==

Всякая сходящаяся последовательность ограничена.

**Свойства сходящихся последовательностей комплексных чисел:**

1. $\lim\limits_{n \to \infty}(z_n \pm t_n) = \lim\limits_{n \to \infty} z_n \pm \lim\limits_{n \to \infty} t_n$;
2. $\lim\limits_{n \to \infty}(z_n \cdot t_n) = \lim\limits_{n \to \infty} z_n \cdot \lim\limits_{n \to \infty} t_n$;
3. $\lim\limits_{n \to \infty}\dfrac{z_n}{t_n} = \dfrac{\lim\limits_{n \to \infty} z_n}{\lim\limits_{n \to \infty} t_n}$, при $t_n \neq 0$, $\lim\limits_{n \to \infty} t_n \neq 0$.

## Предел функции комплексного переменного

Пусть $w = f(z)$ определена и однозначна в окрестности точки $z_0$, за исключением, быть может, самой точки $z_0$.

>**Предел функции** $w = f(z)$ в точке $z_0$ — число $A$, если для любого $\varepsilon > 0$ существует $\delta > 0$ такое, что для всех $z \neq z_0$, удовлетворяющих неравенству $|z - z_0| < \delta$, выполняется неравенство $|f(z) - A| < \varepsilon$.

Определение предела с использованием математической символики:

$$\forall \varepsilon > 0\ \exists \delta > 0\ \forall z:\ |z - z_0| < \delta \Rightarrow |f(z) - A| < \varepsilon \tag{11}$$

>**Эквивалентное определение (по Гейне)** — число $A$ называется пределом функции $w = f(z)$ в точке $z_0$, если для любой последовательности $\{z_n\}$, $z_n \neq z_0$, сходящейся к точке $z_0$, соответствующая последовательность значений функции $\{f(z_n)\}$ сходится к одному и тому же комплексному числу $A$.

Обозначение:

$$\lim_{z \to z_0} f(z) = A \tag{12}$$

==**Теорема о покомпонентном пределе**==

Функция $f(z) = u(x, y) + iv(x, y)$ в точке $z_0 = x_0 + iy_0$ имеет предел $A = B + iC$ ($B, C \in \mathbb{R}$) тогда и только тогда, когда в точке $(x_0, y_0)$ функции $u = u(x, y)$ и $v = v(x, y)$ имеют соответственно пределы

$$\lim_{\substack{x \to x_0 \\ y \to y_0}} u(x, y) = B, \quad \lim_{\substack{x \to x_0 \\ y \to y_0}} v(x, y) = C \tag{13}$$

**Свойства пределов функций комплексного переменного:**

1. $\lim\limits_{z \to z_0} (c_1 f_1(z) \pm c_2 f_2(z)) = c_1 \lim\limits_{z \to z_0} f_1(z) \pm c_2 \lim\limits_{z \to z_0} f_2(z)$;
2. $\lim\limits_{z \to z_0} (f_1(z) \cdot f_2(z)) = \lim\limits_{z \to z_0} f_1(z) \cdot \lim\limits_{z \to z_0} f_2(z)$;
3. $\lim\limits_{z \to z_0} \dfrac{f_1(z)}{f_2(z)} = \dfrac{\lim\limits_{z \to z_0} f_1(z)}{\lim\limits_{z \to z_0} f_2(z)}$, при $\lim\limits_{z \to z_0} f_2(z) \neq 0$.

## Непрерывность функции комплексного переменного

>**Непрерывность в точке** — функция $f(z)$ называется непрерывной в точке $z_0$, если она определена в этой точке и в некоторой её окрестности и

$$\lim_{z \to z_0} f(z) = f(z_0) \tag{14}$$

>**Непрерывность через приращение** — функция $f(z)$ называется непрерывной в точке $z_0$, если бесконечно малому приращению аргумента соответствует бесконечно малое приращение функции:

$$\lim_{z \to 0} \Delta f(z) = 0 \tag{15}$$

>**Непрерывность в области** — функция $f(z)$ непрерывна в области $D$, если она непрерывна в каждой точке этой области.

Сумма, разность и произведение двух функций комплексного переменного, непрерывных в области $D$, также являются непрерывными функциями в этой области.

Функция $\dfrac{f(z)}{g(z)}$ непрерывна только в тех точках области $D$, для которых $g(z) \neq 0$.

Если функция $f(z)$ непрерывна в точке $z_0$, а функция $F(\tau)$ непрерывна в точке $\tau_0 = f(z_0)$, то сложная функция $F(f(z))$ непрерывна в точке $z_0$.

## Основные элементарные функции комплексного переменного

### Показательная функция

>**Показательная функция** — функция, определяемая соотношением

$$w = e^z = e^{x + iy} = e^x(\cos y + i\sin y) \tag{16}$$

**Свойства показательной функции:**

1. $e^{z_1} e^{z_2} = e^{z_1 + z_2}$;
2. $e^{z_1} : e^{z_2} = e^{z_1 - z_2}$;
3. $(e^z)^n = e^{nz}$, $n \in \mathbb{N}$;
4. $e^z \neq 0$;
5. $\lim\limits_{x \to -\infty} e^z = 0$, $\lim\limits_{x \to +\infty} e^z = \infty$;
6. показательная функция — периодическая с мнимым основным периодом $2\pi i$:

$$e^{z + 2\pi i} = e^z \tag{17}$$

Если $x = 0$, $y = \varphi$, получаем классическую формулу Эйлера:

$$e^{i\varphi} = \cos\varphi + i\sin\varphi \tag{18}$$

### Логарифмическая функция

>**Логарифмическая функция** — функция, обратная показательной:

$$w = \operatorname{Ln} z \tag{19}$$

**Свойства логарифмической функции:**

1. $\operatorname{Ln} z$ определена на всей плоскости $z$, кроме точки $z = 0$;
2. $\operatorname{Ln}(z_1 z_2) = \operatorname{Ln} z_1 + \operatorname{Ln} z_2$;
3. $\operatorname{Ln}\dfrac{z_1}{z_2} = \operatorname{Ln} z_1 - \operatorname{Ln} z_2$;
4. $\operatorname{Ln} z^n = n\operatorname{Ln} z$;
5. $\operatorname{Ln}\sqrt[n]{z} = \dfrac{1}{n}\operatorname{Ln} z$.

### Степенная функция

>**Степенная функция** — функция вида $w = z^n$.

$$w = z^n \tag{20}$$

Если $n \in \mathbb{N}$, то

$$w = z^n = r^n(\cos n\varphi + i\sin n\varphi) \tag{21}$$

Если $n = \dfrac{1}{q}$, $q \in \mathbb{N}$, то

$$w = \sqrt[q]{z} = \sqrt[q]{r}\left(\cos\frac{\varphi + 2\pi k}{q} + i\sin\frac{\varphi + 2\pi k}{q}\right), \quad k \in \{0, 1, 2, \ldots, q-1\} \tag{22}$$

Если $n = \alpha + i\beta$, то

$$w = z^n = e^{n\operatorname{Ln} z}, \quad z \neq 0 \tag{23}$$

Если $n = \dfrac{p}{q}$, $p, q \in \mathbb{N}$, то

$$w = \sqrt[q]{|z|^p}\left(\cos\frac{p(\arg z + 2k\pi)}{q} + i\sin\frac{p(\arg z + 2k\pi)}{q}\right) \tag{24}$$

### Дробно-рациональная функция

>**Дробно-рациональная функция** — функция вида

$$w = \frac{a_0 z^n + a_1 z^{n-1} + \ldots + a_n}{b_0 z^m + b_1 z^{m-1} + \ldots + b_m} \tag{25}$$

В частности, рациональной функцией является многочлен

$$w = a_0 z^n + a_1 z^{n-1} + \ldots + a_n \tag{26}$$

### Тригонометрические функции

Из формулы Эйлера $e^{i\varphi} = \cos\varphi + i\sin\varphi$ для действительных $y$ получаем

$$e^{iy} = \cos y + i\sin y, \quad e^{-iy} = \cos y - i\sin y \tag{27}$$

Откуда

$$\sin y = \frac{e^{iy} - e^{-iy}}{2i}, \quad \cos y = \frac{e^{iy} + e^{-iy}}{2} \tag{28}$$

>**Тригонометрические функции** $\sin z$, $\cos z$, $\operatorname{tg} z$, $\operatorname{ctg} z$ для любого комплексного числа $z$ определяются по формулам:

$$\sin z = \frac{e^{iz} - e^{-iz}}{2i}, \quad \cos z = \frac{e^{iz} + e^{-iz}}{2} \tag{29}$$

$$\operatorname{tg} z = \frac{\sin z}{\cos z}, \quad \operatorname{ctg} z = \frac{\cos z}{\sin z} \tag{30}$$

Данные функции сохраняют свойства тригонометрических функций действительного переменного, например:

$$\sin^2 z + \cos^2 z = 1, \quad \sin 2z = 2\sin z\cos z \tag{31}$$

Функции $\sin z$, $\cos z$ в комплексной области являются неограниченными:

$$\lim_{\operatorname{Im} z \to \pm\infty} \sin z = \infty, \quad \lim_{\operatorname{Im} z \to \pm\infty} \cos z = \infty \tag{32}$$
