# Комплексные числа. Действия с ними

## Основные определения

>**Комплексное число** $z$ — выражение вида $z = x + iy$, где $x$ и $y$ — действительные числа, а $i$ — мнимая единица, $i^2 = -1$.

Частные случаи:
1. если $x = 0$, то число $0 + iy = iy$ называется **чисто мнимым**;
2. если $y = 0$, то число $x + i0 = x$ отождествляется с действительным числом $x$, а значит, $\mathbb{R} \subset \mathbb{C}$.

>**Действительная часть** комплексного числа $z = x + iy$ — число $x$, обозначается $x = \operatorname{Re} z$.

>**Мнимая часть** комплексного числа $z = x + iy$ — число $y$, обозначается $y = \operatorname{Im} z$.

## Равенство комплексных чисел

>**Равенство** $z_1 = z_2$ — два комплексных числа $z_1 = x_1 + iy_1$ и $z_2 = x_2 + iy_2$ равны тогда и только тогда, когда равны их действительные и мнимые части: $x_1 = x_2$, $y_1 = y_2$.

В частности, комплексное число $z = x + iy$ равно нулю тогда и только тогда, когда $x = y = 0$. Понятия «больше» и «меньше» для комплексных чисел не вводятся.

## Сопряжённые числа

>**Сопряжённые числа** — два комплексных числа $z = x + iy$ и $\bar{z} = x - iy$, отличающиеся лишь знаком мнимой части.

## Геометрическое изображение комплексного числа

Всякое комплексное число $z = x + iy$ можно изобразить точкой $M(x; y)$ плоскости $Oxy$ такой, что $x = \operatorname{Re} z$, $y = \operatorname{Im} z$. И наоборот, каждую точку $M(x; y)$ координатной плоскости можно рассматривать как образ комплексного числа $z = x + iy$.

**Комплексная плоскость** — плоскость, на которой изображаются комплексные числа:
- ось абсцисс — **действительная ось**, на ней лежат действительные числа $z = x + 0i = x$;
- ось ординат — **мнимая ось**, на ней лежат чисто мнимые числа $z = 0 + iy$.

## Модуль и аргумент

Комплексное число $z = x + iy$ можно задавать с помощью радиус-вектора $\vec{r} = \overline{OM} = (x; y)$.

>**Модуль** комплексного числа $|z| = r$ — длина вектора $\vec{r}$, изображающего это число.

>**Аргумент** комплексного числа $\operatorname{Arg} z = \varphi$ — величина угла между положительным направлением действительной оси и вектором $\vec{r}$.

Модуль однозначно определяется по формуле

$$r = |z| = \sqrt{x^2 + y^2} \tag{1}$$

*Пример 1: Модуль мнимой единицы*  
$$|i| = \sqrt{0^2 + 1^2} = 1$$

Аргумент определяется из формул

$$\cos\varphi = \frac{x}{r}, \quad \sin\varphi = \frac{y}{r}, \quad \operatorname{tg}\varphi = \frac{y}{x} \tag{2}$$

## Формы записи комплексного числа

### Алгебраическая форма

>**Алгебраическая форма** — запись комплексного числа в виде $z = x + iy$.

### Тригонометрическая форма

Модуль $r$ и аргумент $\varphi$ можно рассматривать как полярные координаты вектора $\vec{r} = \overline{OM}$, изображающего комплексное число $z = x + iy$. Тогда $x = r\cos\varphi$, $y = r\sin\varphi$, и комплексное число записывается в виде

$$z = r(\cos\varphi + i\sin\varphi) \tag{3}$$

>**Тригонометрическая форма** — запись комплексного числа в виде (3).

### Показательная форма

Используя формулу Эйлера

$$e^{i\varphi} = \cos\varphi + i\sin\varphi,$$

комплексное число $z = r(\cos\varphi + i\sin\varphi)$ можно записать в виде

$$z = re^{i\varphi} \tag{4}$$

где $r = |z|$ — модуль комплексного числа;  
$\varphi = \operatorname{Arg} z = \arg z + 2k\pi$, $k = 0, \pm1, \pm2, \ldots$

>**Показательная (экспоненциальная) форма** — запись комплексного числа в виде (4).

## Действия с комплексными числами

### Сложение

>**Сумма** двух комплексных чисел $z_1 = x_1 + iy_1$ и $z_2 = x_2 + iy_2$ — комплексное число

$$z_1 + z_2 = (x_1 + x_2) + i(y_1 + y_2) \tag{5}$$

### Умножение

>**Произведение** двух комплексных чисел $z_1 = x_1 + iy_1$ и $z_2 = x_2 + iy_2$ — комплексное число, определяемое равенством ниже.

В алгебраической форме:

$$z_1 z_2 = (x_1 x_2 - y_1 y_2) + i(x_1 y_2 + y_1 x_2) \tag{6}$$

В тригонометрической форме:

$$z_1 z_2 = r_1 r_2\bigl(\cos(\varphi_1 + \varphi_2) + i\sin(\varphi_1 + \varphi_2)\bigr) \tag{7}$$

### Возведение в степень

==**Формула Муавра**==

$$z^n = \bigl(r(\cos\varphi + i\sin\varphi)\bigr)^n = r^n(\cos n\varphi + i\sin n\varphi) \tag{8}$$

### Деление

Деление определяется как действие, обратное умножению.

>**Частное** двух комплексных чисел $z_1$ и $z_2 \neq 0$ — комплексное число $z$ такое, что $z_2 z = z_1$; обозначается $z = \dfrac{z_1}{z_2}$.

В алгебраической форме:

$$z = \frac{z_1}{z_2} = \frac{x_1 x_2 + y_1 y_2}{x_2^2 + y_2^2} + i\,\frac{y_1 x_2 - x_1 y_2}{x_2^2 + y_2^2} \tag{9}$$

В тригонометрической форме:

$$\frac{r_1(\cos\varphi_1 + i\sin\varphi_1)}{r_2(\cos\varphi_2 + i\sin\varphi_2)} = \frac{r_1}{r_2}\bigl(\cos(\varphi_1 - \varphi_2) + i\sin(\varphi_1 - \varphi_2)\bigr) \tag{10}$$

### Извлечение корня

Извлечение корня $n$-й степени — действие, обратное возведению в натуральную степень.

>**Корень $n$-й степени** из комплексного числа $z$ — комплексное число $\omega$ такое, что $\omega^n = z$; обозначается $\omega = \sqrt[n]{z}$.

$$\sqrt[n]{r(\cos\varphi + i\sin\varphi)} = \sqrt[n]{r}\left(\cos\frac{\varphi + 2\pi k}{n} + i\sin\frac{\varphi + 2\pi k}{n}\right) \tag{11}$$

где $k = 0, 1, \ldots, n - 1$.
