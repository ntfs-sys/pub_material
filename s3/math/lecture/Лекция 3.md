# Достаточные признаки сходимости ряда с положительными членами

## Признак Даламбера

Пусть дан положительный ряд

$$a_1 + a_2 + a_3 + \ldots + a_n + \ldots = \sum_{n=1}^{\infty} a_n.$$

Если существует предел отношения $(n+1)$-го члена к $n$-му члену и он равен некоторому числу $l$, т.е.

$$\lim_{n \to \infty} \frac{a_{n+1}}{a_n} = l,$$

то

1) если $l < 1$ — ряд сходится;
2) если $l > 1$ — ряд расходится.

### Доказательство

**1.** Пусть существует предел отношения $(n+1)$-го члена к $n$-му члену, равный $l$:

$$\lim_{n \to \infty} \frac{a_{n+1}}{a_n} = l,$$

и пусть $l < 1$. Докажем, что ряд $\sum_{n=1}^{\infty} a_n$ сходится.

Если $l < 1$, то можно указать такое положительное число $\varepsilon > 0$, что $l + \varepsilon < 1$.

Пусть $l + \varepsilon = r < 1$.

Т.к. $l$ есть предел последовательности $\left\{ \frac{a_{n+1}}{a_n} \right\}$, то для этого числа $\varepsilon$, согласно определению предела последовательности, можно указать такое натуральное число $N(\varepsilon)$, что для всех $n \geq N$ будет справедливо неравенство

$$\left| \frac{a_{n+1}}{a_n} - l \right| < \varepsilon$$

или

$$l - \varepsilon < \frac{a_{n+1}}{a_n} < l + \varepsilon.$$

Рассмотрим правую часть этого неравенства

$$\frac{a_{n+1}}{a_n} < l + \varepsilon = r \quad \text{для всех } n \geq N.$$

Отсюда

$$\frac{a_{n+1}}{a_n} < r \quad \text{или} \quad a_{n+1} < r \cdot a_n \quad \text{для } n \geq N.$$

Положим в этом неравенстве $n = N, N+1, N+2, \ldots$

Тогда получим такие неравенства

$n = N$ $\quad$ $a_{N+1} < r \cdot a_N$

$n = N+1$ $\quad$ $a_{N+2} < r \cdot a_{N+1} < r^2 \cdot a_N$

$n = N+2$ $\quad$ $a_{N+3} < r^3 \cdot a_N$

Рассмотрим два ряда

$$a_{N+1} + a_{N+2} + a_{N+3} + \ldots \tag{1}$$

$$r a_N + r^2 a_N + r^3 a_N + \ldots \tag{2}$$

Ряд (2) есть геометрическая прогрессия со знаменателем $r < 1$. Значит, ряд (2) сходящийся. Сравним каждый член ряда (1) с соответствующим членом ряда (2). Каждый член ряда (1) меньше соответствующего члена ряда (2). Следовательно, по признаку сравнения ряд (1) сходится.

Ряд (1) — остаток ряда $\sum_{n=1}^{\infty} a_n$. Но если сходится остаток ряда, то сходится и сам ряд. Итак, исходный ряд $\sum_{n=1}^{\infty} a_n$ тоже сходится.

**2.** Пусть предел отношения $(n+1)$-го члена к $n$-му члену равен $l$

$$\lim_{n \to \infty} \frac{a_{n+1}}{a_n} = l \quad \text{и} \quad l > 1.$$

Т.к. $l > 1$, то можно указать такое $\varepsilon > 0$, что $l - \varepsilon > 1$.

Пусть $l - \varepsilon = q > 1$.

Для этого $\varepsilon > 0$, согласно определению предела последовательности, можно указать натуральное число $N(\varepsilon)$, что для всех $n \geq N$ будет справедливо неравенство

$$\left| \frac{a_{n+1}}{a_n} - l \right| < \varepsilon \quad \text{или} \quad q = l - \varepsilon < \frac{a_{n+1}}{a_n} < l + \varepsilon.$$

Рассмотрим только левую часть этого неравенства

$$\frac{a_{n+1}}{a_n} > q > 1; \text{ отсюда } a_{n+1} > a_n.$$

Члены ряда возрастают с возрастанием номера.

Следовательно, $n$-ый член ряда не стремится к нулю при возрастании номера $n$, т.е. не выполняется необходимый признак сходимости ряда. Значит, ряд $\sum_{n=1}^{\infty} a_n$ расходится.

**Замечание.** В случае, когда $l = 1$, этот признак не дает возможности судить о поведении ряда. Получаем неопределённость. Для выяснения вопроса о сходимости ряда необходимы дальнейшие исследования.

### Пример

*Пример 1: Исследование ряда по признаку Даламбера*

Исследовать на сходимость числовой ряд:

$$\frac{1}{1} + \frac{1}{1 \cdot 2} + \frac{1}{1 \cdot 2 \cdot 3} + \ldots + \frac{1}{n!} + \ldots$$

Исследуем его по признаку Даламбера.

$$\lim_{n \to \infty} \frac{a_{n+1}}{a_n} = \lim_{n \to \infty} \frac{n!}{(n+1)!} = \lim_{n \to \infty} \frac{1 \cdot 2 \cdot 3 \cdot \ldots \cdot n}{1 \cdot 2 \cdot 3 \cdot \ldots \cdot n \cdot (n+1)} = \lim_{n \to \infty} \frac{1}{n+1} = 0.$$

$l = 0$, $l < 1$ — ряд сходится.

## Признак Коши

Пусть дан положительный ряд

$$a_1 + a_2 + a_3 + \ldots + a_n + \ldots = \sum_{n=1}^{\infty} a_n.$$

Если существует предел корня $n$-ой степени из общего члена ряда и он равен некоторому числу $l$, т.е.

$$\lim_{n \to \infty} \sqrt[n]{a_n} = l,$$

то

1) если $l < 1$ — ряд сходится;
2) если $l > 1$ — ряд расходится.

### Доказательство

**1.** Пусть $\lim_{n \to \infty} \sqrt[n]{a_n} = l$ и $l < 1$. Докажем, что ряд $\sum_{n=1}^{\infty} a_n$ сходится.

Возьмём $\varepsilon > 0$ такое, чтобы $l + \varepsilon < 1$. Пусть $l + \varepsilon = r < 1$.

Т.к. $l$ есть предел последовательности $\{\sqrt[n]{a_n}\}$, то согласно определению предела последовательности, для этого $\varepsilon > 0$ можно указать такое $N(\varepsilon)$, что для всех $n \geq N$ будет справедливо неравенство

$$\left| \sqrt[n]{a_n} - l \right| < \varepsilon \quad \text{или} \quad l - \varepsilon < \sqrt[n]{a_n} < l + \varepsilon = r.$$

Рассмотрим только правую часть этого неравенства:

$$\sqrt[n]{a_n} < r < 1.$$

Отсюда

$$a_n < r^n \quad \text{для } n \geq N.$$

$n = N$ $\quad$ $a_N < r^N$

$n = N+1$ $\quad$ $a_{N+1} < r^{N+1}$

$n = N+2$ $\quad$ $a_{N+2} < r^{N+2}$

Рассмотрим два ряда

$$a_N + a_{N+1} + a_{N+2} + \ldots \tag{1}$$

$$r^N + r^{N+1} + r^{N+2} + \ldots \tag{2}$$

Ряд (2) есть геометрическая прогрессия со знаменателем $r < 1$. Значит, этот ряд сходится. Каждый член ряда (1) меньше соответствующего члена ряда (2), и ряд (2) сходится. Значит, по теореме сравнения рядов ряд (1) тоже сходится.

Но ряд (1) есть остаток ряда $\sum_{n=1}^{\infty} a_n$. Если сходится остаток ряда, то сходится и сам ряд. Значит, ряд $\sum_{n=1}^{\infty} a_n$ сходится.

**2.** Пусть предел корня $n$-ой степени из $n$-го члена равен $l$

$$\lim_{n \to \infty} \sqrt[n]{a_n} = l \quad \text{и} \quad l > 1.$$

Докажем, что ряд $\sum_{n=1}^{\infty} a_n$ расходится.

Возьмём $\varepsilon > 0$ такое, что $l - \varepsilon > 1$. Согласно определению предела последовательности, для этого $\varepsilon > 0$ можно указать такое $N(\varepsilon)$, что для всех $n > N$ будет справедливо неравенство

$$\left| \sqrt[n]{a_n} - l \right| < \varepsilon \quad \text{или} \quad l - \varepsilon < \sqrt[n]{a_n} < l + \varepsilon.$$

Рассмотрим левую часть неравенства $\sqrt[n]{a_n} > l - \varepsilon$, но $l - \varepsilon > 1$, значит, $\sqrt[n]{a_n} > 1$. Отсюда

$$a_n > 1.$$

Это означает, что при возрастании $n$ общий член ряда $\sum_{n=1}^{\infty} a_n$ не стремится к нулю, т.е. не выполняется необходимый признак сходимости ряда. Значит, ряд $\sum_{n=1}^{\infty} a_n$ расходится.

**Замечание.** Если $l = 1$, то мы не можем судить о поведении ряда по признаку Коши. Получаем неопределённость. Нужно провести дополнительные исследования.

### Пример

*Пример 2: Исследование ряда по признаку Коши*

Исследовать на сходимость числовой ряд:

$$2 + \left(\frac{2}{2}\right)^2 + \left(\frac{2}{3}\right)^3 + \left(\frac{2}{4}\right)^4 + \ldots + \left(\frac{2}{n}\right)^n + \ldots$$

Исследуем его по признаку Коши.

$$\lim_{n \to \infty} \sqrt[n]{a_n} = \lim_{n \to \infty} \frac{2}{n} = 0 < 1$$

Ряд сходится.

## Интегральный признак Коши

Для рядов, к которым признаки Даламбера и Коши не применимы, приходится искать другие способы, чтобы выяснить вопрос об их сходимости. Одним из таких методов является интегральный признак сходимости ряда. Интегральный признак справедлив только для рядов с монотонно убывающими членами. Он основан на сравнении данного ряда с некоторым интегралом, верхний предел которого бесконечен.

Пусть члены положительного ряда $a_1 + a_2 + a_3 + \ldots + a_n + \ldots$ образуют монотонно убывающую последовательность.

Тогда если члены знакоположительного ряда $\sum_{n=1}^{\infty} a_n$ могут быть представлены как числовые значения некоторой непрерывной монотонно убывающей на промежутке $[1; +\infty)$ функции $f(x)$ так, что $a_1 = f(1), a_2 = f(2), a_3 = f(3), \ldots, a_n = f(n), \ldots$, то

1) если сходится несобственный интеграл $\int\limits_{1}^{\infty} f(x) \, dx$, то сходится и ряд $\sum\limits_{n=1}^{\infty} a_n$;

2) если расходится несобственный интеграл $\int\limits_{1}^{\infty} f(x) \, dx$, то расходится и ряд $\sum\limits_{n=1}^{\infty} a_n$.

### Пример

*Пример 3: Исследование ряда по интегральному признаку Коши*

Исследовать на сходимость числовой ряд:

$$\sum_{n=1}^{\infty} \frac{1}{(n+1)\ln(n+1)}.$$

Применим интегральный признак Коши:

$$a_n = \frac{1}{(n+1)\ln(n+1)}; \quad \text{следовательно} \quad f(x) = \frac{1}{(x+1)\ln(x+1)}.$$

$$\int_1^{\infty} \frac{dx}{(x+1)\ln(x+1)} = \lim_{b \to \infty} \int_1^b \frac{dx}{(x+1)\ln(x+1)} = \lim_{b \to \infty} \int_1^b \frac{d(\ln(x+1))}{\ln(x+1)} = \lim_{b \to \infty} \ln|\ln(x+1)| \bigg|_1^b = \lim_{b \to \infty} [\ln\ln(b+1) - \ln\ln 2] = \infty.$$

Интеграл расходится, следовательно, расходится и данный ряд.
