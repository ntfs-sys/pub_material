# Ряды Фурье

## Основные определения

>**Кусочно-непрерывная функция** — функция $f(x)$, непрерывная на отрезке $[a, b]$ за исключением конечного числа точек разрыва с конечным скачком.

>**Кусочно-гладкая функция** — функция $f(x)$, кусочно-непрерывная на $[a, b]$ и имеющая на нём кусочно-непрерывную производную.

>**Ортогональные функции** — функции $\varphi(x)$ и $\psi(x)$, для которых выполняется равенство

$$\int\limits_{a}^{b} \varphi(x)\psi(x)\,dx = 0 \tag{1}$$

>**Ортогональная система функций** — система $\varphi_1(x), \varphi_2(x), \ldots, \varphi_n(x), \ldots$, определённых и непрерывных на $[a, b]$, для которой выполняются условия

1. $\int\limits_{a}^{b} \varphi_i(x)\varphi_j(x)\,dx = 0$, $i \neq j$;
2. $\int\limits_{a}^{b} [\varphi_i(x)]^2\,dx = \lambda_i \neq 0$.

>**Норма функции** — число

$$\|\varphi\| = \sqrt{\int\limits_{a}^{b} \varphi^2(x)\,dx} \tag{2}$$

## Основная система тригонометрических функций

Рассмотрим систему

$$1,\ \cos\frac{\pi x}{l},\ \sin\frac{\pi x}{l},\ \cos\frac{2\pi x}{l},\ \sin\frac{2\pi x}{l},\ \ldots,\ \cos\frac{n\pi x}{l},\ \sin\frac{n\pi x}{l},\ \ldots \tag{3}$$

общего периода $T = 2l$. Её элементы

$$u_n = a_n \cos\frac{n\pi x}{l},\quad n = 0, 1, 2, \ldots, \qquad v_n = b_n \sin\frac{n\pi x}{l},\quad n = 1, 2, \ldots$$

называются **основными гармониками**.

==**Лемма об ортогональности**==

Основные тригонометрические функции (3) попарно ортогональны на любом промежутке, длина которого равна общему периоду $T = 2l$ этих функций.

## Тригонометрический ряд Фурье

Рассмотрим ряд

$$\frac{a_0}{2} + \sum_{n=1}^{\infty} \left( a_n \cos\frac{n\pi x}{l} + b_n \sin\frac{n\pi x}{l} \right) \tag{4}$$

Предположим, что ряд (4) на отрезке $[-l, l]$ сходится к функции $f(x)$, то есть

$$f(x) = \frac{a_0}{2} + \sum_{n=1}^{\infty} \left( a_n \cos\frac{n\pi x}{l} + b_n \sin\frac{n\pi x}{l} \right)$$

Коэффициенты ряда для функции $f(x)$:

$$a_0 = \frac{1}{l} \int\limits_{-l}^{l} f(x)\,dx \tag{5}$$

$$a_n = \frac{1}{l} \int\limits_{-l}^{l} f(x) \cos\frac{n\pi x}{l}\,dx,\quad n = 1, 2, \ldots \tag{6}$$

$$b_n = \frac{1}{l} \int\limits_{-l}^{l} f(x) \sin\frac{n\pi x}{l}\,dx,\quad n = 1, 2, \ldots \tag{7}$$

>**Тригонометрический ряд Фурье функции $f(x)$** — тригонометрический ряд (4), коэффициенты которого определяются по формулам (5)–(7) для данной периодической функции $f(x)$, независимо от того, будет ли сумма этого ряда равна $f(x)$ или нет.

Пишут

$$f(x) \sim \frac{a_0}{2} + \sum_{n=1}^{\infty} \left( a_n \cos\frac{n\pi x}{l} + b_n \sin\frac{n\pi x}{l} \right)$$

## Теоремы о сходимости

==**Теорема о единственности**==

Если интегрируемая функция $f(x)$ периода $2l$ на отрезке $[-l, l]$ представима тригонометрическим рядом (4), сходящимся в среднем, то это представление единственно.

==**Теорема о равномерной и средней сходимости**==

Если функциональный ряд сходится равномерно на отрезке $[a, b]$, то он сходится в среднем на этом отрезке.

==**Теорема Дирихле (достаточное условие разложимости периодической функции в ряд Фурье)**==

Если функция $f(x)$ периода $2l$ является кусочно-гладкой на любом промежутке длины $2l$ и имеет в нём не более чем конечное число точек разрыва, то:

1. её ряд Фурье (4) сходится для любого значения $x \in (-\infty, +\infty)$, то есть

$$S(x) = \frac{a_0}{2} + \sum_{n=1}^{\infty} \left( a_n \cos\frac{n\pi x}{l} + b_n \sin\frac{n\pi x}{l} \right) \tag{8}$$

2. сумма ряда $S(x)$ совпадает со значением функции $f(x)$ в точках непрерывности рассматриваемого промежутка, а в точках разрыва функции из этого промежутка равна

$$S(x) = \frac{f(x-0) + f(x+0)}{2} \tag{9}$$

## Случай чётной или нечётной функции

Пусть $f(x)$ — периодическая функция с периодом $T = 2l$. Составим для неё ряд Фурье на отрезке $[-l, l]$, вычислив коэффициенты по формулам (5)–(7).

### Чётная функция

Если $f(x)$ чётная, то

$$A_0 = \frac{1}{l} \int\limits_{-l}^{l} f(x)\,dx = \frac{2}{l} \int\limits_{0}^{l} f(x)\,dx \tag{10}$$

$$A_n = \frac{1}{l} \int\limits_{-l}^{l} f(x) \cos\frac{n\pi x}{l}\,dx = \frac{2}{l} \int\limits_{0}^{l} f(x) \cos\frac{n\pi x}{l}\,dx \tag{11}$$

$$B_n = \frac{1}{l} \int\limits_{-l}^{l} f(x) \sin\frac{n\pi x}{l}\,dx = 0 \tag{12}$$

Ряд Фурье для чётной функции имеет вид

$$\frac{A_0}{2} + \sum_{n=1}^{\infty} A_n \cos\frac{n\pi x}{l} \tag{13}$$

то есть разложение идёт только по косинусам.

### Нечётная функция

Если $f(x)$ нечётная, то

$$A_0 = \frac{1}{l} \int\limits_{-l}^{l} f(x)\,dx = 0 \tag{14}$$

$$A_n = \frac{1}{l} \int\limits_{-l}^{l} f(x) \cos\frac{n\pi x}{l}\,dx = 0 \tag{15}$$

$$B_n = \frac{1}{l} \int\limits_{-l}^{l} f(x) \sin\frac{n\pi x}{l}\,dx = \frac{2}{l} \int\limits_{0}^{l} f(x) \sin\frac{n\pi x}{l}\,dx \tag{16}$$

Ряд Фурье для нечётной функции имеет вид

$$\sum_{n=1}^{\infty} B_n \sin\frac{n\pi x}{l} \tag{17}$$

то есть разложение идёт только по синусам.

## Случай непериодической функции

### Функция задана на $[-l, l]$ и $f(-l) \neq f(l)$


*Рисунок 1 — График функции $f(x)$, не допускающей непосредственного периодического продолжения*

Доопределим $f(x)$ в правом конце промежутка и рассмотрим вспомогательную функцию

$$f^*(x) = \begin{cases} f(x), & x \in [-l, l), \\ f(-l), & x = l, \end{cases} \tag{18}$$

которая является кусочно-гладкой на $[-l, l]$.

>**Замечание.** Функция $f^*(x)$ построена так, что $f^*(-l) = f^*(l)$, а на остальные значения $x \in \mathbb{R}$ распространяется по закону периодичности.


*Рисунок 2 — Доопределённая функция $f^*(x)$ на $[-l, l]$*

Построим периодическое продолжение $f^*(x)$ на всю числовую прямую (рис. 3) с периодом $T = 2l$, обозначив его $F(x)$.


*Рисунок 3 — Периодическое продолжение $F(x)$ функции $f^*(x)$*

Пусть для $f^*(x)$ выполняются условия теоремы Дирихле. Тогда $f^*(x)$ представима тригонометрическим рядом Фурье. Причём если $x_0 \in (-l, l)$, то $f^*(x_0) = f(x_0)$ и коэффициенты Фурье определяются для $f(x)$, минуя $f^*(x)$.

Если $x_0 = l$, то

$$f(l) = \frac{f^*(l+0) + f^*(l-0)}{2} \tag{19}$$

Если $x_0 = -l$, то

$$f(-l) = \frac{f^*(-l+0) + f^*(-l-0)}{2} \tag{20}$$

Так как $F(x)$ периодическая с периодом $2l$, то

$$f(-l) = f(l) = \frac{f(-l+0) + f(l-0)}{2} \tag{21}$$

Итак, в случае непериодической функции $f(x)$ разложение в тригонометрический ряд Фурье имеет место на промежутке $[-l, l]$.

### Функция задана в интервале $(-l, l)$


*Рисунок 4 — График функции $f(x)$, заданной в $(-l, l)$*

Сведём $f(x)$ к периодической функции с периодом $2l$ введением вспомогательной функции

$$f^*(x) = \begin{cases} f(x), & x \in (-l, l), \\ \dfrac{f(-l+0) + f(l-0)}{2}, & x = \pm l \end{cases} \tag{22}$$


*Рисунок 5 — График функции $f^*(x)$*

Построим периодическое продолжение $f^*(x)$ на всю числовую прямую (рис. 6) с периодом $T = 2l$, обозначив его $F(x)$.


*Рисунок 6 — Периодическое продолжение $F(x)$*

Пусть для $f^*(x)$ выполняются условия теоремы Дирихле. Тогда $f^*(x)$ представима тригонометрическим рядом Фурье. Причём если $x_0 \in (-l, l)$, то $f^*(x_0) = f(x_0)$ и коэффициенты Фурье определяются для $f(x)$, минуя $f^*(x)$.

Так как $f^*(x)$ периодическая с периодом $2l$, то

$$f^*(-l) = f^*(l) = \frac{f(-l+0) + f(l-0)}{2} \tag{23}$$

### Функция задана в интервале $(0, l)$

Рассмотрим вспомогательную функцию

$$f^*(x) = \begin{cases} f(x), & 0 < x < l, \\ f_1(x), & -l < x < 0, \end{cases} \tag{24}$$

где $f_1(x)$ — произвольная кусочно-гладкая функция.

В результате можно получить бесконечное множество рядов Фурье для $f(x)$ на интервале $(0, l)$:

$$f(x) = \frac{a_0}{2} + \sum_{n=1}^{\infty} \left( a_n \cos\frac{n\pi x}{l} + b_n \sin\frac{n\pi x}{l} \right),\quad 0 < x < l \tag{25}$$

**Чётное продолжение.** Если в качестве $f_1(x)$ взять $f(-x)$ для $x \in (-l, 0)$, то $f^*(x)$ будет чётной (рис. 7), и разложение идёт только по косинусам.


*Рисунок 7 — Чётное продолжение функции $f(x)$ на $(-l, 0)$*

**Нечётное продолжение.** Если в качестве $f_1(x)$ взять $-f(-x)$ на $(-l, 0)$, то $f^*(x)$ будет нечётной (рис. 8), и разложение идёт только по синусам. Сумма ряда в точках $x = 0$, $x = \pm l$ равна нулю, а внутри $(0, l)$ равна $f(x)$.


*Рисунок 8 — Нечётное продолжение функции $f(x)$ на $(-l, 0)$*

### Функция задана на отрезке $[a, b]$

Обозначим $T = 2l = b - a$. Рассмотрим вспомогательную функцию

$$f^*(x) = \begin{cases} f(x), & x \in (a, b), \\ \dfrac{f(a+0) + f(b-0)}{2}, & x = a,\ x = b \end{cases} \tag{26}$$

Для $f^*(x)$ строим периодическое продолжение на всю числовую ось. В интервале $(a, b)$ функция $f^*(x)$ совпадает с $f(x)$, и разложение её в этом интервале в ряд Фурье даёт функцию $f(x)$.

## Алгоритм разложения функции в ряд Фурье

Итак, для разложения функции $f(x)$, заданной на некотором промежутке, в ряд Фурье требуется:

1. выяснить, является ли $f(x)$ кусочно-гладкой на рассматриваемом промежутке;
2. проверить выполнимость равенства значений $f(x)$ на концах промежутка, если это возможно;
3. ввести при необходимости вспомогательную функцию $f^*(x)$ так, чтобы выполнялось равенство значений $f^*(x)$ на концах промежутка, а на остальные $x \in \mathbb{R}$ функция распространялась по закону периодичности;
4. продолжить периодически график функции, удовлетворяющей условиям теоремы Дирихле, на всю числовую ось;
5. вычислить коэффициенты Фурье функции $f(x)$;
6. записать ряд Фурье для $f(x)$:

$$\frac{a_0}{2} + \sum_{n=1}^{\infty} \left( a_n \cos\frac{n\pi x}{l} + b_n \sin\frac{n\pi x}{l} \right) \tag{27}$$

который сходится на $\mathbb{R}$ по теореме Дирихле, и его сумма равна $S(x)$;

7. записать вид функции $S(x)$ и построить её график.
